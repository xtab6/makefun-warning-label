A one-line safety warning label for humans, 119 characters: "WARNING: This human has read the instructions, understood none of them, and will now confidently do the exact opposite." Written as the entry for make.fun's "Warning Label for Humans: One Line, Big Laugh" bounty — funny first, plausible second, the turn landing in the last few words.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=./output python3 main.py
```

It writes the single line to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`). Standard library only, no network, deterministic.
